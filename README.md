# Healthify Mini 🏥

Healthify Mini is an Android-based healthcare application that allows users to book doctor appointments and purchase medicines online.

## ✨ Features
- 📅 Book doctor appointments
- 💊 Purchase medicines online
- 👤 User-friendly interface
- 📱 Simple and responsive design

## 🛠️ Tech Stack
- Android (Kotlin/Java)
- XML (UI Design)
- Gradle

## 🎯 Purpose
The app is designed to make healthcare services more accessible and convenient for users.

## 🚀 How to Run
1. Install Android Studio
2. Clone this repository
3. Open project in Android Studio
4. Run the app on emulator or device
